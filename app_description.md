# App Description

## Проект

- Название: `fitness-app`
- Стек: `React Native`, `Expo`, `TypeScript`
- Назначение: приложение для записи тренировок, упражнений, подходов и краткой итоговой сводки

## Что уже сделано

- Инициализирован проект через `create-expo-app` с шаблоном `blank-typescript`
- Установлены базовые зависимости:
  - `@react-navigation/native`
  - `@react-navigation/native-stack`
  - `react-native-screens`
  - `react-native-safe-area-context`
  - `@react-native-async-storage/async-storage`
  - `axios`
  - `expo-clipboard`
- Создана базовая структура папок внутри `src/`
- Подключен корневой `NavigationContainer` и `Native Stack`
- Реализован onboarding первого запуска:
  - ввод имени
  - генерация локального `uuid`
  - сохранение экземпляра приложения в `AsyncStorage`
- Реализован экран тренировок вместо старого экрана профиля
- Источник тренировок читается из локального файла `temp/data.json`
- Реализован сценарий одной активной тренировки:
  - одновременно может быть активна только одна тренировка
  - активная тренировка восстанавливается после перезапуска приложения
  - при наличии активной тренировки пользователь сразу попадает на ее экран
- На экране тренировки реализованы:
  - просмотр списка упражнений
  - запуск тренировки
  - завершение тренировки
  - подтверждение перед завершением
  - чекбоксы завершенности упражнений
  - добавление подходов через нижнее модальное окно
  - закрытие нижних модальных окон по тапу вне окна и по свайпу вниз за верхнюю drag-зону
  - сохранение подходов по упражнениям в `AsyncStorage`
  - автоподстановка веса из последнего подхода упражнения
- После завершения тренировки:
  - активная тренировка удаляется из хранилища
  - открывается экран списка тренировок
  - показывается нижний modal sheet со сводкой
  - текст сводки автоматически копируется в буфер обмена

## Текущее состояние

- Приложение уже покрывает базовый локальный сценарий тренировки без бэкенда
- Локально сохраняются:
  - экземпляр приложения
  - активная тренировка
  - подходы по каждому упражнению
  - список завершенных упражнений
- Интерфейс ориентирован на простой flow:
  - выбрать тренировку
  - запустить
  - вносить подходы
  - отмечать упражнения
  - завершить и получить сводку
  - быстро закрывать модальные окна тапом по overlay или свайпом вниз

## Договоренности на данный момент

- Локальные данные хранятся в `AsyncStorage`
- Данные экземпляра приложения лежат в ключе `fitness-app/instance`
- Активная тренировка лежит в ключе `fitness-app/active-workout`
- В активной тренировке сохраняются:
  - `alias`
  - `exerciseLogs`
  - `completedExercises`
- Для маршрутизации используется `React Navigation`
- Переменные окружения Expo хранятся через `EXPO_PUBLIC_*`
- Текущая версия работает без серверной синхронизации

## Что делать дальше

1. Добавить историю завершенных тренировок и экран архива.
2. Уточнить доменную модель: что именно означает поле количества в подходе.
3. Добавить редактирование и удаление уже внесенных подходов.
4. Подготовить отправку сводки в мессенджер, заметки или бэкенд.
5. При необходимости вынести каталог тренировок из `temp/data.json` в полноценный локальный слой данных.
