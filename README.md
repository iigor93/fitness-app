# Fitness App

React Native приложение на `Expo` для учета тренировок, упражнений и подходов.

## Что уже реализовано

- базовый проект на `Expo` + `TypeScript`
- onboarding первого запуска с сохранением `name` и локального `uuid`
- экран списка тренировок на основе [temp/data.json](/d:/vscode/personal/fitness-app-front/fitness-app/temp/data.json)
- запуск только одной активной тренировки одновременно
- автопереход в активную тренировку при повторном входе в приложение
- просмотр упражнений внутри тренировки
- добавление неограниченного количества подходов к каждому упражнению
- локальное сохранение подходов и статусов упражнений в `AsyncStorage`
- чекбокс завершения у каждого упражнения
- подтверждение перед завершением тренировки
- итоговая сводка тренировки после завершения
- автоматическое копирование сводки в буфер обмена
- закрытие модальных окон по тапу вне окна и свайпу вниз за верхнюю drag-зону

## Текущий сценарий приложения

1. При старте приложение проверяет наличие сохраненного экземпляра в `AsyncStorage`.
2. Если `uuid` отсутствует, открывается экран ввода имени.
3. После ввода имени приложение генерирует локальный `uuid`, сохраняет данные и открывает экран тренировок.
4. Если активной тренировки нет, показывается список тренировок из `temp/data.json`.
5. Пользователь может открыть тренировку для просмотра упражнений или сразу нажать `Старт`.
6. После старта в локальное хранилище записывается одна активная тренировка с ее `alias`, логами подходов и списком завершенных упражнений.
7. Если активная тренировка уже есть, приложение сразу открывает экран этой тренировки.
8. В активной тренировке можно:
   - добавлять подходы по упражнениям через нижнее модальное окно
   - отмечать упражнения как выполненные
   - видеть сохраненные подходы под каждым упражнением
   - закрывать нижние модальные окна тапом по overlay или свайпом вниз
9. При завершении сначала показывается окно подтверждения.
10. После подтверждения активная тренировка удаляется из хранилища, открывается экран списка тренировок и показывается сводка, которая автоматически копируется в буфер обмена.

## Как проверить текущий flow

1. Запусти приложение в эмуляторе или на устройстве.
2. При первом запуске введи имя и нажми `Продолжить`.
3. Убедись, что открылся экран со списком тренировок.
4. Открой любую тренировку и нажми `Старт тренировки`.
5. Добавь несколько подходов у разных упражнений.
6. Отметь одно или несколько упражнений чекбоксом как выполненные.
7. Перезапусти приложение и проверь, что активная тренировка открывается сразу.
8. Нажми `Завершить тренировку`, подтверди действие и проверь сводку.
9. Убедись, что текст сводки вставляется из буфера обмена.
10. Проверь, что модальное окно ввода подхода и окно сводки закрываются по тапу вне окна и по свайпу вниз.

## Локальное хранение

Используется `AsyncStorage`.

Основные ключи:

- `fitness-app/instance` - локальные данные пользователя
- `fitness-app/active-workout` - активная тренировка, подходы и завершенные упражнения

## Переменные окружения

Создай локально файл `.env` на основе `.env.example`.

Основная переменная:

- `EXPO_PUBLIC_API_URL` - базовый URL бэкенда

## Структура проекта

```text
src/
  app/              # корневой app-компонент
  components/       # переиспользуемые UI-компоненты
  constants/        # ключи и константы приложения
  navigation/       # навигация и типы роутов
  screens/          # экраны onboarding и тренировок
  services/
    api/            # HTTP-клиент и конфиг API
    storage/        # локальное хранилище
  theme/            # цвета и отступы
  types/            # общие типы
temp/
  data.json         # локальный каталог тренировок
```

## Следующие шаги

2. Разделить понятия `повторения` и `подходы`, если это потребуется по бизнес-логике.
3. Подготовить экспорт или отправку сводки на бэкенд.
4. Подключить синхронизацию тренировок между устройством и сервером.
