# Fitness App

React Native приложение на `Expo` для учета тренировок и результатов.

## Что уже подготовлено

- Базовый проект на `Expo` + `TypeScript`
- Структура `src/` для экранов, навигации, компонентов, API и локального хранения
- Подключены `React Navigation`, `AsyncStorage` и `axios`
- Создан `app_description.md` для фиксации прогресса между сессиями
- Реализован стартовый flow первого запуска
- Добавлены 2 стартовых экрана:
  - экран ввода имени
  - экран приветствия с именем пользователя и `uuid`
- Имя и `uuid` сохраняются локально в `AsyncStorage`

## Быстрый старт

```bash
npm install
npm run start
```

Дополнительно:

```bash
npm run android
npm run ios
npm run web
npm run typecheck
npx expo start --clear
```

После запуска Expo:

- нажми `a`, чтобы открыть Android emulator
- нажми `i`, чтобы открыть iOS simulator, если работаешь на macOS
- нажми `w`, чтобы открыть web-версию

## Текущий сценарий приложения

1. При старте приложение проверяет наличие сохраненного экземпляра в `AsyncStorage`.
2. Если `uuid` отсутствует, открывается экран ввода имени.
3. После ввода имени приложение генерирует локальный `uuid`, сохраняет `name` и `uuid`, затем открывает второй экран.
4. Если `uuid` уже есть, приложение сразу открывает экран приветствия.
5. На втором экране можно удалить локальные данные и вернуться к начальному состоянию.

## Как проверить текущий flow

1. Запусти приложение в эмуляторе или на устройстве.
2. При первом запуске введи имя и нажми `Продолжить`.
3. Убедись, что открылся второй экран с приветствием и `uuid`.
4. Перезапусти приложение и проверь, что второй экран открывается сразу.
5. Нажми `Удалить данные` и проверь, что приложение снова показывает экран ввода имени.

## Переменные окружения

Создай локально файл `.env` на основе `.env.example`.

Основная переменная:

- `EXPO_PUBLIC_API_URL` - базовый URL бэкенда

## Структура проекта

```text
src/
  app/              # корневой app-компонент
  components/       # переиспользуемые UI-компоненты
  constants/        # константы приложения
  navigation/       # навигация и типы роутов
  screens/          # экраны приложения
  services/
    api/            # HTTP-клиент и конфиг API
    storage/        # локальное хранилище
  theme/            # цвета и отступы
  types/            # общие типы
```
